row animation

Targeted by e2e/row-animation.spec.ts (mirror of svelte-treeview's /test/row-animation). On by default (part of core motion, no on/off attribute): rows an expand reveals get wtv__node--opening (capped by row-animation-limit); never on first render, a re-render or a data reload.

--wtv-row-animation-duration: 0s → just the rows are off.

No attribute (on by default), limit 3, a 1s duration.

motion="none" → 0s → no reveal.

Default tokens (transition-normal) — reduced motion zeroes it.
