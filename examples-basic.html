What makes a row's left offset

A row sits in by toggle gutter + content padding + (level − 1) × indent. The indentation buttons only move --wtv-indent-size — multiplied by (level − 1), so at the root that's × 0 and the root rows never move. The fixed part left of every label (highlighted amber above) is the toggle column (--wtv-toggle-icon-width, reserved on every row so leaf labels align under branch labels) plus the content's left --wtv-node-padding — independent of indent.

To tighten the root gap, lower --wtv-toggle-icon-width (and/or --wtv-node-padding); to change nesting density, use --wtv-indent-size. All inherit through the Shadow DOM when set inline on <web-treeview>, so rows re-flow instantly.

BU04 · Custom Data Mappings

Map your own data shape to the tree using id-member, path-member, and display-value-member attributes.

// Your data can use any property names
const data = [
  { categoryId: 1, categoryPath: "1", label: "Electronics", ... },
  { categoryId: 2, categoryPath: "1.1", label: "Phones", ... }
];

// Map them to tree properties
element.setAttribute('id-member', 'categoryId');
element.setAttribute('path-member', 'categoryPath');
element.setAttribute('display-value-member', 'label');

BU06 · Accordion Expand

With expand-as-accordion="true", opening one branch automatically collapses its siblings at the same level. Useful when you want only one section open at a time (e.g. file managers, settings panels). User-driven toggles honor it; programmatic expandNodes() calls are unaffected.

Try expanding "src", then "public" — with accordion on, opening "public" auto-collapses "src". Untick the box and the two sections can stay open together.
