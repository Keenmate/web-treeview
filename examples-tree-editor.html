TE01 · Interactive Tree Editor

Click a node to select it (the toolbar acts on the focused node). Use the controls to add a child, add a sibling, rename, delete, or move up / down. You can also drag nodes to reorder, or right-click a node for the same actions in a context menu. The JSON panel on the right reflects the live tree data after every mutation.

TE03 · Editor API

            
The mutation and clipboard methods used on this page. Call them on the
               <web-treeview> element (the facade proxies them to the controller).


            

                
                    
MethodDescription

                
                
                    
addNode(parentPath, data, pathSegment?)Add a new node under a parent ('' = root). Returns { success, node, error? }.

                    
removeNode(path, includeDescendants?)Remove a single node (and optionally its descendants).

                    
updateNode(path, dataUpdates)Patch a node's data in place (e.g. rename).

                    
moveNode(sourcePath, targetPath, position)Move a node. position is 'before' | 'after' | 'child'.

                    
insertBranch(parentPath, data[])Insert several nodes under a parent in one batch.

                    
replaceBranch(parentPath, data[])Replace a parent's children with a new set.

                    
deleteBranch(path, keepParent?)Delete a whole subtree (optionally keep the parent).

                    
deleteNodes(paths?)Delete the given paths (defaults to the highlight set). Returns { removed, blocked }.

                    
copyNodes(paths?) / cutNodes(paths?)Snapshot onto the shared cross-tree clipboard (defaults to highlight set).

                    
pasteNodes(targetPath, transform?, position?)Insert clipboard content; returns a PasteResult ({ success, count, skipped }).

                    
cancelCut() / hasClipboardContent() / getClipboardOperation()Clear a pending cut; query the clipboard state.

                    
getSiblings(path) / getChildren(parentPath)Read the tree structure (used by Move up / down).

                    
getSelectedPaths() / getHighlightedPaths() / focusNode(path)Selection & focus accessors.

                    
getAllData() / getNodeByPath(path)Snapshot all node data; look up one node.

                    
contextMenuCallback(node, close) => ContextMenuEntry[]Build the right-click menu entries for a node.

                
            


            

                
orderMember + move positions

                

                    Set order-member="sortOrder" so before/after moves keep siblings ordered. The
                    move positions are 'before', 'after', and 'child'
                    (matching svelte-treeview's DropPosition).
                

            


            


// Add a child under the focused node (or at root)
const parent = tree.getController().focusedNode;
tree.addNode(parent?.path ?? '', {
  id: Date.now(), path: '', name: 'New Node', icon: '📄', sortOrder: 100
});

// Rename in place
tree.updateNode(path, { name: 'Renamed' });

// Move among siblings
const siblings = tree.getController().getSiblings(path);
const i = siblings.findIndex(s => s.path === path);
if (i > 0) tree.moveNode(path, siblings[i - 1].path, 'before');

// Clipboard: copy selection, paste under a target with fresh ids
tree.copyNodes();                       // defaults to the highlight set
let nextId = 9000;
tree.pasteNodes(targetPath, (data) => ({ ...data, id: nextId++ }), 'child');

// Right-click menu
tree.contextMenuCallback = (node, close) => [
  { id: 'rename', icon: '✏️', label: 'Rename', onclick: () => renameNode(node.path) },
  { divider: true },
  { id: 'delete', icon: '🗑️', label: 'Delete', className: 'danger',
    onclick: () => tree.removeNode(node.path) },
];
