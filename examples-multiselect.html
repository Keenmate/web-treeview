SL02 · Three-Level Selection Model

The library tracks three independent kinds of selection. Choose which combination fits your UI:

  • focusedNode — single cursor row (clicks, arrow keys). Surfaces as focused-node-changed.
  • highlightedPaths — multi-select set (Ctrl/Shift+click). Surfaces as highlight-change. Drives the highlight CSS class.
  • selectedPaths — data state for checkboxes. Surfaces as selection-change. Independent from focus/highlight unless shouldShowCheckboxes is off (then highlight mirrors into it).

SL04 · Keyboard Navigation

Click any node to give the tree focus, then use keyboard shortcuts:

Keyboard shortcuts
  • ↓ / ↑ — Next / previous sibling
  • → — Expand and move to first child
  • ← — Move to parent node
  • Backspace — Collapse parent and move to it
  • Enter / Space — Toggle expand/collapse
  • Home / End — First / last visible node
  • Escape — Deselect all
