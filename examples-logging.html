Logging & Debugging

The global window.components registry, category logging controls, performance timings, and the in-tree debug overlay

Open the DevTools Console (F12). On load the component registers itself on window.components['web-treeview']. Try window.components['web-treeview'] in the console, then use the buttons below — the logging story here goes through that global, nothing else.

LG01 · The registry entry

Every KeenMate component publishes one entry via core's registerComponent(). Below is a live view of window.components['web-treeview'], refreshed automatically as instances connect and disconnect.

window.components['web-treeview']

LG02 · Logging controls — via .logging

The .logging object is the flattened logger bundle. These buttons call it directly (e.g. window.components['web-treeview'].logging.setCategoryLevel('DATA','debug')). The active category level is reflected in the registry panel above. Interact with the trees — click, expand/collapse, or right-click a node (UI), or drag a node in the second tree (DRAG) — to produce logs.

LG03 · Live instances — .getInstances()

getInstances() returns the connected elements of this tag — maintained automatically (added on connect, removed on disconnect). Add and remove trees below and watch the count in the registry panel change; then fan a call out across every live instance.

LG04 · Performance logging

Perf logging lives in its own module (enablePerfLogging / setPerfThreshold, imported from @keenmate/web-treeview) — it is not part of the .logging category bundle above. Enable it, then load a large dataset to see render timings in the console.

LG05 · Debug information overlay

Toggle the in-tree debug overlay (the should-display-debug-information input) to inspect internal node state directly on the tree.

LG06 · Log categories

  • INIT — component initialization, configuration parsing, destruction
  • DATA — data insertion, tree building, node updates
  • INDEX — search indexing operations
  • UI — DOM rendering, node reconciliation, context menu
  • DRAG — drag start/over/leave/drop, cross-tree detection, touch drag
  • RENDER — progressive rendering batches, render-coordinator timing

LG07 · Usage

// No import needed at call sites — the registry is a global, populated the
// moment the component module is loaded anywhere on the page.
const tv = window.components['web-treeview'];

tv.version();                       // "2.0.0-rc08"
tv.config;                          // { name, version, author, license, … }
tv.getInstances();                  // live <web-treeview> elements

// Logging (a flattened view of the core logger bundle)
tv.logging.getCategories();         // ["INIT","DATA","INDEX","UI","DRAG","RENDER"]
tv.logging.enableLogging();         // all categories → debug
tv.logging.setLogLevel('info');     // all → info
tv.logging.setCategoryLevel('INDEX', 'debug');
tv.logging.disableLogging();        // silence everything (production default)

// Fan out across instances
for (const el of tv.getInstances()) console.log(el.id, [...el.getExpandedPaths()]);

// Perf logging is a SEPARATE module (not on tv.logging) — import it directly:
import { enablePerfLogging, setPerfThreshold } from '@keenmate/web-treeview';
enablePerfLogging();
setPerfThreshold(5);                // only log operations taking > 5ms
