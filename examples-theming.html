TH01 · Built-in Dark Mode

Three signals flip the tree's surface between light and dark, applied in order of precedence (highest first):

  1. theme="dark" / theme="light" attribute on the <web-treeview> — per-instance override, beats everything else.
  2. OS preference via @media (prefers-color-scheme: dark) — auto-flips when the user's OS is in dark mode.
  3. Library defaults — light, with #1a1a1a as the dark fallback when a signal does flip.

Each block re-declares --wtv-bg-color, --wtv-text-color, etc. with sensible fallbacks. To customize, set the --base-* tokens on an ancestor and they cascade through the Shadow DOM.

Tree B follows your OS preference. Toggle your OS dark mode to see it flip.

TH04 · Toggle Icon Set & Icon Reskin

The disclosure glyph is driven by CSS custom properties. Switch between the built-in iconSet presets, or reskin the chevron globally through the shared --base-icon-chevron contract — the same override a design system applies across every KeenMate component at once.

Setting --base-icon-chevron on the host flows into --wtv-icon-expand through the shadow boundary, so the whole tree's chevron swaps to a custom mask. plus-minus is a swap set (distinct expand/collapse glyphs); the others rotate a single glyph.

TH05 · CSS Custom Properties Reference

Two layers of CSS custom properties are available. --base-* variables come from the design system and cascade to all components. --wtv-* variables are treeview-specific and reference --base-* with hardcoded fallbacks.

/* ── Design System tokens (--base-*) ── set on :root or container */
/* These cascade to ALL components sharing the design system */

--base-accent-color: #3b82f6;        /* Primary accent color */
--base-text-color-1: #1e293b;          /* Primary text color */
--base-text-color-3: #64748b;        /* Secondary text color */
--base-main-bg: #ffffff;            /* Background color */
--base-border-color: #e2e8f0;        /* Border color */
--base-hover-bg: #f1f5f9;           /* Hover background */
--base-active-bg: #e2e8f0;          /* Active/pressed background */
--base-elevated-bg: #f8f9fa;           /* Light background */
--base-accent-color-light: #eff6ff; /* Light accent background */
--base-rem: 10px;                    /* Base unit for sizing */

/* ── Component tokens (--wtv-*) ── set on <web-treeview> */
/* These override the design system for this component only */

--wtv-accent-color     /* = --base-accent-color */
--wtv-text-color       /* = --base-text-color-1 */
--wtv-text-color-2     /* = --base-text-color-3 */
--wtv-bg-color         /* = --base-main-bg */
--wtv-border-color     /* = --base-border-color */
--wtv-hover-bg         /* = --base-hover-bg */
--wtv-selected-bg      /* = --base-accent-color-light */
--wtv-node-height      /* = calc(--wtv-rem * 3.2) */
--wtv-node-padding     /* = --wtv-spacing-sm --wtv-spacing-md */
--wtv-indent-size      /* = calc(--wtv-rem * 2) */
--wtv-font-size        /* = --wtv-font-size-sm (14px) */
--wtv-border-radius-sm /* = calc(--base-border-radius-sm * --wtv-rem) */
--wtv-transition-speed /* = 150ms */
