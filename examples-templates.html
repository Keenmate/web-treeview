Custom node rendering, context menus, loading/empty states, per-node icons, and unified column-width alignment

TP01 · Custom Node Template

Use renderNodeCallback to render custom HTML for each tree node. This example shows file icons and sizes.

element.renderNodeCallback = (node, container) => {
    const ext = getExtension(node.data.name);
    container.innerHTML = `
        <div class="custom-node">
            <span class="file-icon">${getIcon(ext)}</span>
            <span class="name">${node.data.name}</span>
            <span class="file-size">${node.data.size}</span>
        </div>
    `;
};

TP04 · Node-Aware Context Menu

Use renderContextMenuItemCallback to render completely custom HTML per menu item. The callback replaces the button's inner content — you control the layout. The outer <button> with classes, data-* attributes, disabled state, and submenu hover behavior is still managed by the component. Debug mode is on by default so the controls below preview live.

Action:

Right-click a person to see a rich context menu
// Customize specific items, leave the rest to default rendering.
// If the callback populates the container → custom rendering.
// If it leaves the container empty → default icon+label+shortcut.
tree.renderContextMenuItemCallback = (item, node, container) => {
    if (item.id === 'profile') {
        const initials = node.data.name.split(' ').map(w => w[0]).join('');
        container.innerHTML = `
            <span class="avatar">${initials}</span>
            <span class="info">
                <span>${node.data.name}</span>
                <span class="role">${node.data.role}</span>
            </span>`;
        return;
    }
    if (item.id === 'invoices') {
        container.innerHTML = `
            <span class="wtv__context-menu-icon">🧾</span>
            <span class="wtv__context-menu-label">Invoices</span>
            <span class="count-chip">${node.data.invoiceCount}</span>`;
        return;
    }
    // No innerHTML set → default rendering used for this item
};

TP07 · FontAwesome Icons

Use FontAwesome classes for toggle and leaf icons. Inject FA stylesheet into Shadow DOM via customStylesCallback.

// Inject FontAwesome into Shadow DOM via customStylesCallback
tree.customStylesCallback = () =>
    `@import url('https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.7.2/css/all.min.css');`;

// Rotate mode — single chevron rotates 90°
<web-treeview
    expand-icon-class="fa-solid fa-chevron-right"
    leaf-icon-class="fa-regular fa-file">

// Swap mode — two different icons
<web-treeview
    toggle-icon-mode="swap"
    expand-icon-class="fa-regular fa-folder"
    collapse-icon-class="fa-regular fa-folder-open"
    leaf-icon-class="fa-regular fa-file-lines">

TP10 · Per-Node Icons via iconMember

Each node has an icon field in its data containing a CSS class. The tree reads it via iconMember="icon".

// Data with icon field
{ id: 1, path: '1', name: 'Documents', icon: 'icon-folder' }
{ id: 2, path: '1.1', name: 'report.pdf', icon: 'icon-file-pdf' }

// Usage
element.iconMember = 'icon';
// or via attribute:
// <web-treeview icon-member="icon">

TP11 · Per-Node Icons via iconCallback

Dynamically resolve icon classes from node data. The callback receives the full LTreeNode and returns CSS class(es) or null.

element.iconCallback = (node) => {
  if (node.hasChildren) return 'icon-folder';
  const ext = node.data.name.split('.').pop();
  return extensionIconMap[ext] || 'icon-file';
};
