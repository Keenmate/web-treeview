Theming Scenarios

1. No signal (baseline light)

No prop, no brand theme. Expected: white.

2. Per-instance theme="dark"

Forwarded as data-theme="dark". Expected: library dark default.

3. Per-instance theme="light"

Forwarded as data-theme="light". Expected: white.

4. Brand theme (light-dark())

Wrapper sets --base-main-bg: light-dark(red, green). Light page = RED, dark page = GREEN.
