PF05 · What to Test

  1. Initial render: Generate data with different node counts and expand levels. Compare render times between modes.
  2. Expand/Collapse ONE node: The key test! Use "Expand One" and "Collapse One" buttons. This is the typical user interaction.
  3. Expand/Collapse ALL: Bulk operations - compare performance between flat and virtual scroll.
  4. Search/Filter: Toggle between filter mode (live) and search mode (Enter to navigate between matches).
Expected Results
  • Flat mode: All visible nodes rendered to the DOM. Fast expand/collapse for single nodes.
  • Virtual Scroll: Only ~50 nodes in the DOM regardless of tree size. Near-instant rendering for any dataset size.
  • Virtual scroll should shine on initial render and expand all. Single-node expand may be similar.
