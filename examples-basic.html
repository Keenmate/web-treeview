Basic Usage

Simple tree rendering, expand/collapse, node selection, and hierarchical data

BU01 · Simple File Tree

A basic tree with hierarchical data using path-based structure. Click nodes to select, click the toggle icon to expand/collapse.

Indentation:

Indent width is a single CSS variable — --wtv-indent-size (default 16px), the per-level step in flat mode (paddingLeft = (level − 1) × --wtv-indent-size). It's separate from the toggle column (--wtv-column-width), so nesting density tunes independently. The buttons set it inline on the <web-treeview> element; custom properties inherit through the Shadow DOM, so the rows re-flow instantly.

BU04 · Custom Data Mappings

Map your own data shape to the tree using id-member, path-member, and display-value-member attributes.

// Your data can use any property names
const data = [
  { categoryId: 1, categoryPath: "1", label: "Electronics", ... },
  { categoryId: 2, categoryPath: "1.1", label: "Phones", ... }
];

// Map them to tree properties
element.setAttribute('id-member', 'categoryId');
element.setAttribute('path-member', 'categoryPath');
element.setAttribute('display-value-member', 'label');

BU06 · Accordion Expand

With accordion-expand="true", opening one branch automatically collapses its siblings at the same level. Useful when you want only one section open at a time (e.g. file managers, settings panels). User-driven toggles honor it; programmatic expandNodes() calls are unaffected.

Try expanding "src", then "public" — with accordion on, opening "public" auto-collapses "src". Untick the box and the two sections can stay open together.
